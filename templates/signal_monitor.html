📡 About Signal Monitor

Signal Monitor shows the Wi-Fi networks around you with live signal strength, and inventories the devices and servers on your own active local network — tracking new or offline devices over time as alerts. It never scans networks you aren't connected to.

The three columns

  • Wi-Fi Signals — every nearby Wi-Fi network this machine can see, with signal strength, channel, and security type. Click one to load its devices on the right.
  • Devices — everything found on the selected network: online/offline status, IP, MAC address, vendor, and any open ports (likely services).
  • Alerts — a running log of network events: a new device joining, or a previously-seen device going offline.

Each column scrolls independently — the header stays put while you scroll through its list.

Toolbar buttons

  • Auto-refresh — how often the page automatically re-polls for fresh data (4s / 8s / 20s / Off).
  • Rescan current network — forces an immediate fresh scan instead of waiting for the next auto-refresh.
  • All connected interfaces — shows devices across every active network interface (Wi-Fi + Ethernet + VPN, etc.), not just the default Wi-Fi network.
  • Export CSV — downloads the latest device scan as a CSV file.
  • Connect to this network — joins a nearby Wi-Fi network directly from the dashboard (enter its password when prompted).
  • Trace — runs a traceroute to a device's IP, showing each network hop between this machine and that device.

Terms

  • SSID — the name of a Wi-Fi network.
  • Signal % — Wi-Fi signal strength; higher is stronger (90%+ excellent, under 30% weak/unreliable).
  • Channel — the radio frequency the network broadcasts on.
  • Security — the protocol protecting the network, e.g. WPA2, WPA3, or Open (unsecured).
  • MAC Address — a hardware ID unique to each network device.
  • Vendor — the device manufacturer, inferred from its MAC address.
  • Open Ports / Running Services — network services detected on a device (e.g. a printer, web server, or file share).
  • New Device / Device Offline — alert types: a device seen for the first time, or one that has stopped responding.
  • Hop (traceroute) — one router/network step data travels through between this machine and the target device.
  • Bandwidth (24h) — total data sent and received by this machine over the last 24 hours.
