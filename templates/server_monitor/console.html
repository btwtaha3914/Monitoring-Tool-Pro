🖥️ About the Server Console

This is a single-page console for investigating one server IP at a time. Public IPs are scanned directly over the internet; private (LAN) IPs are reached by connecting through a VPN profile you upload. Only scan IPs you own or are authorized to monitor.

Target type toggle

  • Public IP — an internet-facing address (e.g. a website's server). Scanned directly.
  • Private IP — a LAN address (e.g. 192.168.x.x, 10.x.x.x). Reachable only after connecting to a VPN that has access to that network.

Buttons

  • ▶ Run Discovery — runs the full public-IP scan: geolocation, WHOIS/RDAP ownership lookup, reverse DNS, open ports, HTTP headers, SSL certificate, hosted-domain discovery, and (if provided) SNMP.
  • 🔌 Connect via VPN & Scan — uploads your .ovpn profile, opens the tunnel, then scans the private IP over it.
  • ⏻ Disconnect VPN — closes the VPN tunnel opened by the private scan.

Fields & terms

  • SNMP Community String — a read-only password some network devices use for monitoring software (like PRTG/Zabbix) to query their internal status. Optional — leave blank to skip this check.
  • Geolocation — the approximate physical location the IP is registered to.
  • WHOIS / RDAP — public registration records: who owns the IP block and which network it belongs to.
  • Open Ports — which network services are listening and reachable (e.g. 80 = HTTP, 443 = HTTPS, 22 = SSH).
  • SSL / TLS Certificate — the server's HTTPS certificate details and expiry.
  • Domains & Websites Hosted Here — other domains found to be pointing at or served from this same IP.
