🌐 About Web Monitor

Web Monitor checks whether a website and its subdomains are up, how fast they respond, and whether their SSL certificate is healthy. Enter a root domain (e.g. example.com) and it automatically discovers subdomains, then checks each one live.

Buttons

  • Check Domain — starts a live scan.
  • Save to Watchlist — saves the root domain for future reference.
  • View (in History) — reopens a past scan with all its results.
  • Click a subdomain — opens a deep analysis modal (DNS/HTTP/SSL details).
  • Click an IP address — jumps to Server Monitor with the IP pre-filled and lookup auto-running.

Summary cards

  • Total Targets — how many domains/subdomains were checked.
  • Websites UP — targets that responded successfully.
  • Websites DOWN — targets that failed to respond.
  • Degraded — targets that responded with a warning (e.g. HTTP 4xx).
