Server Monitoring Dashboard

Monitor domains, servers and subdomains in real time

🌐 About Web Monitor

Web Monitor checks whether a website and its subdomains are up, how fast they respond, and whether their SSL certificate is healthy. Enter a root domain (e.g. example.com) and it automatically discovers subdomains via certificate transparency logs, then checks each one.

Buttons

  • Check Domain — starts a scan: discovers subdomains for the domain you typed, then runs a live HTTP/DNS/SSL check against every one of them.

Summary cards

  • Total Targets — how many domains/subdomains were found and checked.
  • Websites UP — targets that responded successfully.
  • Websites DOWN — targets that failed to respond (timeout, connection refused, DNS failure, etc.).
  • Degraded — targets that responded, but slowly or with a warning-level issue (e.g. a redirect or an expiring certificate).

Results table columns

  • Domain — the domain or subdomain checked.
  • IP Address — the IP it resolved to.
  • DNS — whether the domain name resolved successfully.
  • Server — whether the server accepted a connection on a common port (80/443).
  • Website — whether an HTTP response was received.
  • HTTP — the HTTP status code returned (e.g. 200, 404, 500).
  • Response — how long the server took to respond, in milliseconds.
  • Diagnosis — a plain-language summary of what's wrong, if anything.
